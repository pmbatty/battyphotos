# battyphotos

Wildlife photography reference projects by Peter Batty, served from GitHub Pages
as an umbrella for things eventually intended to live at
[batty.photos](https://batty.photos/).

Live: <https://pmbatty.github.io/battyphotos/>

## Sub-projects

- **[noise-sharpening/](./noise-sharpening/)** — full-resolution comparison of
  noise-reduction, sharpening, and upsizing tools applied to the same wildlife
  photographs. Companion to a May 2026 MHWPC digital training session.

## Build

The site is a static collection of HTML, CSS, and JS, plus pre-built JPEGs and
JSON data files generated by a Python build script.

```sh
pip install -r tools/requirements.txt
python tools/build-site.py --source ~/Pictures/MHWPC-training-noise-sharpening
```

The build script reads Lightroom-exported JPEGs from a source folder outside the
repo, generates web-sized images and detail crops, extracts AI critiques from
[darwain](https://github.com/pmbatty/darwain) JSON sidecars, and writes the
results into `noise-sharpening/images/` and `noise-sharpening/data/`.

See [comparison-website-requirements.md](./comparison-website-requirements.md)
and [docs/plans/](./docs/plans/) for full design documentation.
